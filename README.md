# NAF Sheets

محطة ناف لربط ملفات **Google Sheets الموجودة** بمشاريع **Basecamp 5**، بمزامنة في الاتجاهين على أعمدة ثابتة. الفريق يعمل في الملف وفي Basecamp؛ المنصة للربط والإعداد والمتابعة فقط.

**المنصة مستثناة من نظام تصميم ناف (`naf-ui`)** بقرار المالك. التفصيل في `CLAUDE.md` §0.

| الملف | ما فيه |
|---|---|
| [`docs/station-plan.md`](docs/station-plan.md) | الفكرة والقرارات المعتمدة والمراحل (المرجع الحالي) |
| [`docs/user-guide.md`](docs/user-guide.md) | دليل الاستخدام |
| [`docs/cloudflare-setup.md`](docs/cloudflare-setup.md) | النشر والمتغيرات والأسرار |
| [`docs/google-service-account.md`](docs/google-service-account.md) | حساب خدمة Google |
| [`CLAUDE.md`](CLAUDE.md) | القرارات المعمارية وقواعد العمل والأوامر |
| [`docs/spec.md`](docs/spec.md) | مواصفة المحرّر السابقة (مستبدلة، للتاريخ) |
| `spike/` | كود المرحلة 0 للمحرّر السابق: أدلة لا أساس للبناء |

**الحالة (2026-11-15):** المحطة مبنية ومختبرة محلياً على Google وBasecamp وهميين. القبول الحي ينتظر النشر وأول ربط حقيقي (`docs/station-plan.md` §9).
