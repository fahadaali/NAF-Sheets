# NAF Sheets

منصة ناف لإدارة مشاريع الاتصال المؤسسي: محرّر جداول يحاكي تجربة Google Sheets، وكل ملف فيه مشروعٌ في Basecamp 5 بمزامنة في الاتجاهين.

**المنصة مستثناة من نظام تصميم ناف (`naf-ui`)** بقرار المالك، فهي منصة مختلفة واستثنائية. التفصيل في `CLAUDE.md` §0.

| الملف | ما فيه |
|---|---|
| [`docs/spec.md`](docs/spec.md) | المواصفات المعتمدة للتنفيذ (الإصدار 1.0) |
| [`docs/phase-0-report.md`](docs/phase-0-report.md) | نتائج اختبار الجدوى، والقرارات المطلوبة قبل المرحلة 1 |
| [`CLAUDE.md`](CLAUDE.md) | القرارات المعمارية وقواعد العمل والأوامر |
| `spike/` | كود المرحلة 0: أدلة لا أساس للبناء |

**الحالة:** المرحلة 0 بانتظار الاعتماد، والمرحلة 1 لم تبدأ.
